# Quarto Reveal.js template: Health Policy in Switzerland

## Files
- `slides.qmd`: example slide deck
- `_quarto.yml`: project-wide settings
- `custom.scss`: visual design
- `references.bib`: bibliography

## Use in RStudio
1. Install Quarto if needed: https://quarto.org
2. Open this folder as an RStudio project or open `slides.qmd` directly.
3. Click **Render**.
4. The output is an HTML presentation.
5. Press `F` in the browser for full-screen mode.
6. Press `S` to open speaker view.

## Editing the design
Most visual changes are in `custom.scss`.
The current template uses a restrained academic design with one blue accent colour, large section dividers, clean typography, and minimal transitions.
